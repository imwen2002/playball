# 後台選手出賽檢核：支援多位選手同時獨立展開與一鍵全展開

已完成後台【3 場地循環排程表】中的「選手出賽檢核」展開機制修改：

## 1. 完成項目

1. **獨立多選持續展開**：
   - 將狀態從原本單一選取的 `expandedPlayerStats: string | null` 升級為獨立集合 `expandedPlayerIds: Set<string>`。
   - 點擊任一選手卡片時，該選手獨立切換展開/收合狀態，不再互相排斥；展開後會持續維持展開，直到再次點擊同一選手卡片才收回。
   - 主辦人可同時展開多位或全體選手，自由對照各選手的 4 場出賽輪次、場地編號、隊友與對手。

2. **新增「展開全部 / 全部收回」快捷按鈕**：
   - 於「選手出賽完整檢核表」標題右側增設快捷按鈕：
     - `展開全部`：一鍵將當前賽程中所有選手的出賽明細全部展開。
     - `全部收回`：一鍵將所有已展開卡片收折為精簡卡片。

## 2. 修改檔案
- `src/components/AdminDashboard.tsx`
  - 新增 `expandedPlayerIds` 狀態與 `togglePlayerStatsExpanded`、`handleToggleAllPlayerStats` 處理函式。
  - 在檢核表區塊頂端增加「展開全部」與「全部收回」操作按鈕。
  - 將卡片展開條件與點擊事件切換為獨立集合比對。
